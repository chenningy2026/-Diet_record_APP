# Diet Record App

這是我第一個用 GitHub 建立的作品紀錄頁，用來練習把設計作品整理成可以公開展示的網頁，並記錄製作歷程。

## 專案目標

練習整理一個飲食紀錄 App 的作品集頁面，理解 GitHub repository、HTML、CSS、README 與 GitHub Pages 的基本關係。

## 製作歷程

- 建立 GitHub repository
- 新增 index.html
- 新增 style.css
- 將 style.css 連接到 index.html
- 準備用 GitHub Pages 發布成公開網頁

## 我目前學到的事

- GitHub 不只是儲存程式碼，也可以記錄作品修改歷程
- index.html 是網頁內容
- style.css 是網頁外觀
- README.md 是作品說明與歷程紀錄
- commit message 可以讓別人看到我每一步做了什麼
